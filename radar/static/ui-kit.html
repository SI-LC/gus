Gus UI kit

Every cockpit screen is built from these parts. Use them as they are. If a screen needs something new, add it to radar/cockpit.css and to this page first.

The rules
  • One primary button per screen or card: the thing you most likely want to do.
  • A button says what happens ("Shortlist", "Skip"), never "OK" or "Submit".
  • Colour never carries meaning alone: a dot or an edge always comes with words.
  • Colours, fonts and corners come from the tokens below, never a new hex value.
  • Every list has an empty state that says what will appear there.
Colours
